# Pre-Demo Checklist

- [ ] Device preparation (charge, WiFi, DND)
- [ ] App setup (Zomato, Amazon logged in, carts empty, addresses saved)
- [ ] FlowPilot setup (API key, accessibility service, permissions)
- [ ] Recording setup (screen brightness, no notifications, close other apps)
- [ ] Pre-recording test (run the exact demo sequence once)
- [ ] Submission items (APK, source code, README, architecture diagram)
