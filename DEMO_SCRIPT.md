# Demo Script: FlowPilot

**[0:00-0:10] Title — FlowPilot — Teach once. Replay anything.**
- *Tip:* Keep the intro crisp and clearly state the value proposition.

**[0:10-1:40] TEACH (T1) — Say "Order a Margherita pizza from Domino's on Zomato", then demonstrate the full ordering flow in Zomato. Tap Done.**
- *Tip:* Move deliberately so the Accessibility Service captures every meaningful action clearly.

**[1:40-2:25] EXACT REPLAY (T2) — Repeat the same command. Watch automatic replay. Stops at payment.**
- *Tip:* Keep your hands visible but off the screen to emphasize the autonomous replay.

**[2:25-2:55] PARAPHRASE (T3) — Say "Get me a margherita from dominos" — matches and replays.**
- *Tip:* Highlight the system's ability to understand natural language variations.

**[2:55-3:25] CHANGED SLOT (T4) — Say "Order a Farmhouse pizza from Domino's" — finds Farmhouse instead.**
- *Tip:* Emphasize parameter extraction and how the workflow adapts.

**[3:25-3:55] SCREEN CHANGE (T7) — Pre-add item to cart, repeat command. System handles unexpected state.**
- *Tip:* Show the recovery manager in action, handling real-world UI changes.

**[3:55-4:25] CLARIFICATION (T13) — Say "Order pizza on Zomato" with no parameters. System asks for each missing slot.**
- *Tip:* Demonstrate conversational fallback and context awareness.

**[4:25-4:45] UNKNOWN INTENT (T12) — Say "Book a cab to the airport" — system says it hasn't learned that.**
- *Tip:* Shows system boundaries and graceful degradation.

**[4:45-5:00] STATUS (T14) — Ask "Did the last run succeed?" — show execution log.**
- *Tip:* End with transparency and observability.
